# 차량 전조등 눈부심 장애물 인지 시뮬레이터 v2

개선 사항:
- 고급 변수 전체가 계산 또는 센서 품질에 연결됨
- 광원 크기, Bloom, Halo, Veiling glare, 젖은 노면 → 눈부심 영향
- 장애물 좌우 위치 → 카메라 프레이밍 및 초음파 시야 영향
- 장애물 반사율 → 카메라 가시성 영향
- 노출/Gain/HDR → 저조도·포화 손실에 영향
- 초음파 Noise/Dropout → 실시간 화면에서도 결정론적으로 센서 품질·증거에 영향
- 자동 실험 모드에서만 실제 의사난수형 측정 오차/Dropout 적용
- 현재 판단 단계 순서 수정: 안전 → 주의 → 경계
- 현재 계산에 어떤 요인이 영향을 주는지 실시간 설명 표시

주의: 실제 AI 검출 정확도가 아닌 연구용 설명 가능 proxy 시뮬레이션입니다.
